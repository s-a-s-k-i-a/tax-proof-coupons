# Roadmap

## Reliability next

- Add a current licensed WPML/WCML test lane and a maintained Advanced Dynamic Pricing fixture.
- Add Classic Checkout coverage beside Checkout Block and HPOS.
- Add multi-currency matrix tests for currency precision, zero-decimal currencies, and conversion timing.
- Add shipping, taxable fees, compound rates, tax-exempt customers, and sequential-coupon scenarios.

## Maintainer experience

- Publish a compatibility matrix with exact tested versions.
- Add weekly Git tag versus WordPress.org SVN drift monitoring.
- Improve issue forms so reports capture store tax settings and a minimal cart calculation table.

## User-facing improvements

- Add a read-only coupon preview in the editor showing the conceptual gross/net/tax split for a selected example tax rate.
- Add contextual diagnostics to WooCommerce status tools without telemetry or customer data.
- Improve translated help text and screenshots once asset ownership and licensing are documented.

Features that turn this plugin into a tax engine, invoice system, licensing system, or remote updater are intentionally out of scope.
